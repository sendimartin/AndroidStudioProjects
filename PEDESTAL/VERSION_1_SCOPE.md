# PEDESTAL - Version 1 Scope

## Customer
- **Register**: Create a new account.
- **Login**: Access existing account.
- **View Products**: Browse available items.
- **Search Products**: Find specific items by name or category.
- **Add to Cart**: Save items for purchase.
- **Checkout**: Complete purchase process.
- **View Orders**: See history and status of purchases.

## Seller
- **Register as Seller**: Upgrade or create account with seller privileges.
- **Add Products**: List new items for sale.
- **Edit Products**: Update product details (price, description, stock).
- **Delete Products**: Remove items from the store.

## Admin
- **Manage Users**: View, edit, or disable user/seller accounts.
- **Manage Products**: Oversee all listings, remove inappropriate content.
- **Manage Orders**: Track and manage all transactions across the platform.
